# Mini Proyecto en Python y SQLite

## Descripción
Este proyecto es una aplicación de consola desarrollada en Python que permite gestionar información utilizando una base de datos SQLite. Su propósito principal es demostrar la implementación práctica de operaciones CRUD (Crear, Leer, Actualizar y Eliminar) mediante programación modular y consultas SQL.

## Tecnologías utilizadas
* **Python 3**: Lenguaje de programación principal.
* **SQLite**: Motor de base de datos relacional integrado.

## Requisitos
* Python 3.x instalado en tu sistema.
* No se requieren librerías de terceros (la librería `sqlite3` viene incluida por defecto en Python).

## Instalación
1. Clona este repositorio o descarga el código fuente en formato ZIP.
   
2. Descomprime los archivos y guárdalos en una carpeta de tu preferencia.

## ¿Cómo ejecutar el proyecto?
1. Abre una terminal o línea de comandos.
2. Navega hasta el directorio donde se encuentran los archivos del proyecto.
3. Ejecuta el archivo principal con el siguiente comando:
   ```
   python main.py
   ```

## Operaciones disponibles
El sistema cuenta con un menú interactivo que permite realizar las siguientes acciones:
* **Agregar registro**: Inserta nueva información en la base de datos.
* **Consultar registros**: Muestra todos los datos almacenados actualmente.
* **Actualizar registro**: Permite modificar la información de un registro existente buscando por su ID.
* **Eliminar registro**: Borra un registro específico de la base de datos a través de su ID.
